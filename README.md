# Voynich

> Hide your model in plain sight.

Voynich is a Solana protocol for sealed machine learning models. Model weights live on chain as XChaCha20-Poly1305 ciphertext that anyone can inspect and fetch. Only attested enclaves holding a wrapped key grant can decrypt and run them.

Live app: [voynich.dev](https://voynich.dev)
API: `https://api.voynich.dev`
X: [@voynichdotdev](https://x.com/voynichdotdev)
