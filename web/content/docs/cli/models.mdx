---
title: models
description: voynich models and voynich enclaves, the two list commands, with every field they print, and voynich model price, policy and retire, the owner's commands.
---

Two commands list what is on chain: `voynich models` lists sealed models and `voynich enclaves` lists registered enclaves. Both read public state through the API and need no wallet. The same from code is [Models and enclaves](/docs/sdk/models-and-enclaves).

Three more commands change a model as its owner: [`voynich model price`](#voynich-model-price), [`voynich model policy`](#voynich-model-policy) and [`voynich model retire`](#voynich-model-retire), plus [`voynich model versions`](#voynich-model-versions) and [`voynich model upgrade`](#voynich-model-upgrade) for versioned releases.

## voynich models

```bash
voynich models
```

It takes no arguments. It prints one page of models, up to 24, ordered by calls:

<Fields>
<Field name="items" type="array of Model">
The models. Each has the fields below.
</Field>
<Field name="page.nextCursor" type="string or null">
The position of the next page, or `null` on the last one.
</Field>
<Field name="page.hasMore" type="boolean">
Whether more models follow this page.
</Field>
<Field name="asOf" type="ISO 8601 time">
When the API read this state.
</Field>
</Fields>

### Model fields

What each field means on chain is told in [Sealed models](/docs/concepts/sealed-models).

<Fields>
<Field name="address" type="address">
The Model account.
</Field>
<Field name="name" type="string">
The model's name, such as `sketch-32`. Commands take the name or the address.
</Field>
<Field name="owner" type="address">
The wallet that sealed the model.
</Field>
<Field name="createdSlot" type="integer string">
The slot the Model was created in.
</Field>
<Field name="sealedSlot" type="integer string or null">
The slot the ciphertext hash was fixed in. `null` while the model is `uploading`.
</Field>
<Field name="sizeBytes" type="integer">
The ciphertext's size.
</Field>
<Field name="plaintextSizeBytes" type="integer">
The weights file's size before encryption.
</Field>
<Field name="ciphertextSha256" type="64 hex characters or null">
The SHA-256 of the ciphertext. `null` while the model is `uploading`.
</Field>
<Field name="cipher" type="object">
`id` (`xchacha20poly1305-64k-v1`), `chunkSizeBytes` (`65536`) and `noncePrefix` (16 bytes, base64).
</Field>
<Field name="allowedMeasurements" type="array of 96 hex characters">
The measurements whose enclaves can be granted the model key.
</Field>
<Field name="price" type="object">
The unit price of the model (per call when `priceUnit` is `call`, or per output token when `token`): `amount` in base units as a string, `mint` (an address, or `null` for SOL), `decimals` and `symbol`.
</Field>
<Field name="priceUnit" type="'call' | 'token'">
Whether `price` is charged per `call` or per output `token`.
</Field>
<Field name="operatorShareBps" type="integer">
The operator's share of each settled call, in basis points.
</Field>
<Field name="protocolShareBps" type="integer or null">
The protocol share, in basis points.
</Field>
<Field name="status" type="string">
`uploading`, `sealed`, `live` or `retired`.
</Field>
<Field name="manifest" type="object">
`name`, `inputKind` (`sketch` or `tensor`), `inputShape`, `labels`, and `inputName`, `outputName` and `preprocess`: always for a `sketch` model, where the model states them for a `tensor` model.
</Field>
<Field name="weights" type="array">
The model's Weights accounts in order. Each has `address`, `model`, `index`, `offset` (where its bytes start in the ciphertext), `sizeBytes` and `writtenRanges` (a list of `offset` and `length`).
</Field>
<Field name="upload" type="object or null">
The upload: `uploadKey`, `bytesWritten`, `transactionsWritten`, `writtenRanges` and `closed`. `upload` is `null` from sealing on.
</Field>
<Field name="enclavesHolding" type="integer">
How many enclaves hold a grant for the model that is not revoked, with an attestation record in force.
</Field>
<Field name="callsSettled" type="integer string">
How many calls to the model have settled.
</Field>
<Field name="hasPolicy" type="boolean">
Whether the model has an active on-chain `Policy` PDA (`["policy", model]`).
</Field>
</Fields>

### Enclave fields

What each field means is told in [Enclaves and attestation](/docs/concepts/enclaves-and-attestation).

<Fields>
<Field name="address" type="address">
The Enclave account. `voynich grant` and `voynich seal --enclave` take it.
</Field>
<Field name="signingKey" type="address">
The enclave's Ed25519 key. It signs every receipt.
</Field>
<Field name="encryptionKey" type="32 bytes, base64">
The enclave's X25519 key. Inputs and the model key are encrypted to it.
</Field>
<Field name="hardwareType" type="string">
`dev`, `tdx` or `sev-snp`.
</Field>
<Field name="measurement" type="96 hex characters">
The measurement of the software the enclave runs. An owner allows it with `voynich seal --measurement`.
</Field>
<Field name="expiresAtSlot" type="integer string">
The slot the enclave's attestation record expires at.
</Field>
<Field name="operator" type="address">
The operator's wallet. It receives the operator share.
</Field>
<Field name="endpoint" type="URL">
Where the enclave runtime listens.
</Field>
<Field name="relayPath" type="string">
`/v1/calls/{call}/input`: the path, on the API and on the enclave's `endpoint` alike, that takes a call's encrypted input.
</Field>
<Field name="status" type="string">
`live` or `expired`.
</Field>
<Field name="reachable" type="boolean">
Whether the enclave's endpoint answered the API's last health request as this enclave. Callers are sent to live, reachable enclaves. See [Reachability](/docs/api/enclaves#reachability).
</Field>
<Field name="lastSeen" type="ISO 8601 time or null">
When the endpoint last answered as this enclave. `null` until it first does.
</Field>
<Field name="modelsHeld" type="integer">
How many models the enclave holds a grant for.
</Field>
<Field name="callsSettled" type="integer string">
How many calls the enclave has settled.
</Field>
<Field name="attestation" type="object">
The enclave's attestation record: `address`, `signingKey`, `encryptionKey`, `hardwareType`, `measurement`, `recordedSlot`, `expiresAtSlot` and `layoutVersion`.
</Field>
</Fields>

## voynich model price

```bash
voynich model price <model> --price <base units> [--price-unit <call|token>]
```

Sets a model's price, price unit and operator share with `set_price`, signed by the owner's wallet. Calls that open after it pay the new price and unit. The same from code is [setPrice](/docs/sdk/grant-and-refund#setprice).

<Fields>
<Field name="model" type="name or address, argument" required>
The model to price.
</Field>
<Field name="--price" type="integer string" required>
The unit price (per call or per output token), in base units of the price's unit: lamports for SOL, the mint's smallest unit for a mint.
</Field>
<Field name="--price-unit" type="'call' | 'token'">
Whether `--price` is charged per `call` or per output `token`. Left out, the model keeps its current `priceUnit`.
</Field>
<Field name="--operator-share-bps" type="integer, 0 to 10000">
The operator's share of each settled call, in basis points. Left out, the model keeps its share.
</Field>
<Field name="--mint" type="SOL or address">
The unit of the price: `SOL`, or the address of an SPL Token mint. Left out, the model keeps its unit.
</Field>
<Field name="--decimals" type="integer">
The decimals of the price's unit. Required with a mint other than the model's. Left out, it is `9` for SOL and the model's decimals when the mint stays.
</Field>
<Field name="--symbol" type="string">
The label shown beside the price. Left out, it is the model's symbol when the mint stays, `SOL` for SOL, and the mint's address for another mint.
</Field>
</Fields>

The wallet is chosen as told in [Install](/docs/cli/install#the-signing-wallet) and has to be the model's owner. The command reads the model first to fill in what the flags leave out.

It prints the status of the transaction, as JSON on stdout: `id`, `status` (`confirmed` or `finalized`) and `signature`.

| Code | Message | Cause |
| --- | --- | --- |
|  | `Supply model.` or `Supply --price.` | A missing argument or flag. |
|  | `--price-unit must be call or token.` | `--price-unit` is neither `call` nor `token`. |
|  | `Supply --decimals for a new SPL mint.` | `--mint` names a mint other than the model's, without `--decimals`. |
| `MODEL_NOT_FOUND` | The API's message | No model has this name or address. |
| `VALIDATION_ERROR` | The API's message | A value is not what its flag takes. |
| `SIMULATION_FAILED` | The API's message | The wallet is not the model's owner, or the operator share plus the protocol share is above 10,000. |
| `TRANSACTION_FAILED`, `TRANSACTION_EXPIRED` | The failure's own message, or `The transaction did not land.` | `set_price` was refused, or did not land before its blockhash expired. |

## voynich model policy

Reads, creates, updates or clears a model's on-chain `Policy` PDA (`["policy", model]`). The same from code is [policy, setPolicy and clearPolicy](/docs/sdk/models-and-enclaves#policy-setpolicy-and-clearpolicy).

```bash
voynich model policy show <model>
voynich model policy set <model> [--allow-list] [--caller <pubkey> ...] [--max-calls <n>] [--window-slots <slots>] [--operator <pubkey> ...] [--region <region> ...]
voynich model policy clear <model>
```

<Fields>
<Field name="show <model>" type="read">
Reads the model's active `ModelPolicy` through `GET /v1/models/{id}/policy` (no wallet required). Prints the policy JSON, or `{ "model": "<model>", "policy": null }` when none exists.
</Field>
<Field name="set <model>" type="owner write">
Signs `set_policy` as the model's owner, waits for indexing, and prints `{ "model", "policy", "transaction" }`. Repeatable flags: `--caller` (up to 32 unique addresses), `--operator` (up to 16 unique addresses), and `--region` (up to 8 unique lowercase alphanumeric/hyphen codes, 1 to 16 characters each). Pass `--allow-list` to enforce `allowedCallers`; pass `--max-calls` (`0` to `4294967295`) and `--window-slots` (both `0` or both positive) to set per-caller rate ceilings.
</Field>
<Field name="clear <model>" type="owner write">
Signs `clear_policy` as the model's owner, closing the `Policy` PDA and returning its rent to the owner. Prints `{ "model", "cleared": true, "transaction" }`.
</Field>
</Fields>

| Code | Message | Cause |
| --- | --- | --- |
|  | `Use model policy show <model>, model policy set <model>, or model policy clear <model>.` | Subcommand is not `show`, `set` or `clear`. |
|  | `--max-calls must be an integer between 0 and 4294967295.` or `--window-slots must be a non-negative integer.` | Invalid rate-limit flag. |
| `MODEL_NOT_FOUND` | The API's message | No model has this name or address. |
| `POLICY_NOT_FOUND` | The API's message | `clear` called on a model with no active Policy PDA. |
| `VALIDATION_ERROR`, `INVALID_POLICY` | The API's message | Duplicate addresses/regions, out-of-range counts, or mismatched zero/positive rate limits. |
| `SIMULATION_FAILED` | The API's message | The wallet is not the model's owner. |

## voynich model versions

```bash
voynich model versions <model>
```

Lists a model's versions newest-first through `GET /v1/models/{id}/versions` (no wallet required). Prints `{ "model", "currentVersion", "items", "asOf" }`, where each item holds `address`, `version`, `status` (`uploading`, `live` or `archived`), `sizeBytes`, `ciphertextSha256`, `base`, `manifest` and `publishedSlot`. The same from code is [listVersions](/docs/sdk/models-and-enclaves#listversions-and-publishversion).

## voynich model upgrade

```bash
voynich model upgrade <model> <weights file> [--owner-key <file>] [--manifest <file>] [--base <source> --base-file <file>]
```

Publishes `currentVersion + 1` of a live model at the same name and address without downtime or re-granting enclaves, calling [`publishVersion`](/docs/sdk/models-and-enclaves#listversions-and-publishversion).

<Fields>
<Field name="model" type="name or address, first argument" required>
The live model to upgrade.
</Field>
<Field name="weights file" type="file path, second argument" required>
New plaintext ONNX weights or `voynich/adapter/v1` adapter bytes. Encrypted on this device under the model's existing key with a fresh `noncePrefix`.
</Field>
<Field name="--owner-key / --state" type="file path">
Optional model key source: a 64-character hex file, a 32-byte JSON array, or an encrypted owner key file (prompts for password). When omitted, the CLI derives the deterministic model key from the owner keypair via `signSealDerivation`.
</Field>
<Field name="--manifest" type="file path">
Optional replacement manifest JSON file. When omitted, the model keeps its current manifest.
</Field>
<Field name="--base, --base-file, --base-sha256, --base-size, --base-format" type="flags">
Optional base-model overrides for sealed adapter upgrades (same flags as [`voynich seal`](/docs/cli/seal)). When omitted, the model keeps its current `base`.
</Field>
</Fields>

Prints `{ "model", "name", "version", "ciphertextSha256", "noncePrefix", "transactionsSent" }` as JSON on stdout.

## voynich model retire

```bash
voynich model retire <model>
```

Retires a model with `retire_model`, signed by the owner's wallet. A retired model takes no new calls and no new grants. The same from code is [retire](/docs/sdk/grant-and-refund#retire).

<Fields>
<Field name="model" type="name or address, argument" required>
The model to retire.
</Field>
</Fields>

It prints the status of the transaction: `id`, `status` and `signature`.

| Code | Message | Cause |
| --- | --- | --- |
|  | `Supply model.` | The argument is missing. |
| `MODEL_NOT_FOUND` | The API's message | No model has this name or address. |
| `SIMULATION_FAILED` | The API's message | The wallet is not the model's owner. |
| `TRANSACTION_FAILED`, `TRANSACTION_EXPIRED` | The failure's own message, or `The transaction did not land.` | `retire_model` was refused, or did not land before its blockhash expired. |

`voynich model` followed by another word fails with `Use model price, model policy, model versions, model upgrade, model retire, or model revoke.` The last of them, `voynich model revoke`, is on [grant](/docs/cli/grant#voynich-model-revoke).

## Failures

The two list commands exit with code `1` and print the API's code and message when the API refuses the request. The API's codes are in the [HTTP API overview](/docs/api/overview).
