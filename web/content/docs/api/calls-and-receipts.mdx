---
title: Calls and receipts
description: The call and receipt routes of the Voynich HTTP API, covering opening a call, reading it, polling its answer, refunding it and reading its receipt.
---

Nine routes open, read, stream, stop, self-settle and refund calls and read receipts. The relay route that carries the encrypted input is on [Relay](/docs/api/relay). What a call is, how signed pieces chain, and what a receipt proves are told in [Calls and receipts](/docs/concepts/calls-and-receipts).

Over the API a call is made in this order:

| Step | Route |
| --- | --- |
| Open the call | `POST /v1/calls/build`, then [`POST /v1/transactions/submit`](/docs/api/transactions#post-v1transactionssubmit) |
| Send the encrypted input | [`POST /v1/calls/{id}/input`](/docs/api/relay) |
| Read the answer (per-call) | `GET /v1/calls/{id}/answer` |
| Stream or read signed pieces (per-token) | `GET /v1/calls/{id}/stream` or `GET /v1/calls/{id}/pieces` |
| Stop a live stream early (per-token) | `POST /v1/calls/{id}/stop` |
| Settle a cut-short stream directly (per-token) | `POST /v1/calls/{id}/settle/build` |
| Read the receipt | `GET /v1/receipts/{id}` |
| Take the escrow back when no answer came | `POST /v1/calls/{id}/refund/build` |

In the paths of calls, `{id}` is the Call account's address. The errors every route shares are in [Overview](/docs/api/overview#on-every-route).

## `POST /v1/calls/build`

Builds [`open_call`](/docs/program/instructions#opencall) for a per-call model or [`open_metered_call`](/docs/program/instructions#openmeteredcall) for a per-token model: a Call account with the escrow deposited and the hash of the encrypted input on record.

Before this call, encrypt the input to the enclave's `encryptionKey` and take the SHA-256 of the envelope's bytes, as told in [What is encrypted](/docs/concepts/calls-and-receipts#what-is-encrypted).

```http
POST /v1/calls/build
Content-Type: application/json

{
  "wallet": "<caller address>",
  "model": "<model name or address>",
  "enclave": "<enclave address>",
  "inputHash": "<sha-256 of the input envelope, 64 hex characters>",
  "ceiling": "<optional escrow ceiling in base units, required for per-token models>",
  "nonce": "<unsigned 64-bit integer, decimal>"
}
```

<Fields>
<Field name="wallet" type="address" required>
The caller. It pays the escrow and the fee, and signs.
</Field>
<Field name="model" type="address or name" required>
The model to call.
</Field>
<Field name="enclave" type="address" required>
The Enclave account that answers. It holds a grant for the model. [`GET /v1/models/{id}/enclaves`](/docs/api/models#get-v1modelsidenclaves) lists the candidates, live and reachable ones first.
</Field>
<Field name="inputHash" type="hash" required>
The SHA-256 of the complete input envelope.
</Field>
<Field name="answerMode" type="string">
`sealed` (default) or `open`. An `open` call stores its plaintext answer bytes on chain in the Receipt up to `maxOpenAnswerBytes`.
</Field>
<Field name="ceiling" type="decimal string, unsigned 64-bit">
Maximum escrow in base units of the model's price mint. Required when the model's `priceUnit` is `token` (must be at least the model's per-token price, and above `0` when the price is above `0`), which routes the build to `open_metered_call`. Must be omitted when `priceUnit` is `call`.
</Field>
<Field name="nonce" type="decimal string, unsigned 64-bit">
A number the caller has not used before. With the caller it gives the Call its address. The API draws a random one when it is omitted.
</Field>
</Fields>

Returns a [Build](/docs/api/transactions#build). Its `action` is `open_call` and its `addresses` hold `model` and `call`, the address of the Call the transaction creates. For a price in a mint, the escrowed amount (`model.price` or `ceiling`) leaves the caller's associated token account for that mint.

| Code | When |
| --- | --- |
| `VALIDATION_ERROR` | `ceiling` is missing or below the per-token price for a `token` model, or `ceiling` is supplied for a `call` model. |
| `MODEL_NOT_FOUND` | No model has this name or address. |
| `ENCLAVE_NOT_FOUND` | No Enclave account has the address in `enclave`. |
| `MODEL_NOT_LIVE` | The model is not `live`. |
| `GRANT_REQUIRED` | The enclave's grant for the model is revoked. |
| `ENCLAVE_EXPIRED` | The enclave's attestation record is invalid or expired. |
| `MEASUREMENT_NOT_ALLOWED` | The enclave's measurement is not in the model's `allowedMeasurements`. |
| `INSUFFICIENT_FUNDS` | For a price in SOL: the caller holds fewer lamports than the escrow amount, the Call's rent and the fee. For a price in a mint: the caller's associated token account holds less than the escrow amount, with `funding.mint` the mint, or the caller holds fewer lamports than the Call's rent, the rent of a new escrow token account and the fee. |
| `SIMULATION_FAILED` | The transaction failed in simulation for another reason. `programError` names a program error when there is one. |

The codes every build shares are in [Errors from a build](/docs/api/transactions#errors-from-a-build).

Next: sign and submit the Build, then send the envelope to [`POST /v1/calls/{id}/input`](/docs/api/relay) with `addresses.call` as `{id}`.

## `GET /v1/calls/{id}/answer`

Reads the call's answer. Poll it after the input is sent until `status` leaves `waiting`, or follow [`GET /v1/calls/{id}/events`](/docs/api/overview#event-streams).

Returns a [CallAnswer](#callanswer).

| `status` | The response holds |
| --- | --- |
| `waiting` | The output fields as `null`. The enclave holds no answer for this call. |
| `answered` | `outputEnvelope`, `outputHash`, `signature`, `settleTransaction` and `receiptAddress`. |
| `failed` | `failure`. The output fields are `null`. |

The answer is the enclave's: for a call that is `open` or `settled` the API asks the call's enclave and returns what it holds, with the `call` read by the API. For a call that is `refundable` or `refunded` the API answers `failed` itself. Its `failure` is the call's own: `code` `CALL_DEADLINE_PASSED`, with `refundState` `refundable` or `refunded`.

In a failed answer from the enclave, `failure.code` is `ENCLAVE_EXPIRED` when the enclave's attestation record expired before it answered, and `PROGRAM_REFUSED` when the enclave could not complete the call. `failure.refundState` says where the escrow stands at the moment of the read.

| Code | When |
| --- | --- |
| `VALIDATION_ERROR` | `{id}` is not an address. |
| `CALL_NOT_FOUND` | No call has this address. |
| `ENCLAVE_NOT_FOUND` | The API holds no enclave for the call's `enclave`. |
| `UPSTREAM_UNAVAILABLE` | The enclave did not answer within 60 seconds, or answered with something that is not an answer. Retryable. |

The plaintext of `outputEnvelope` is UTF-8 JSON with two fields: `label`, the name of the highest output, and `scores`, up to five `{ label, probability }` objects, highest first.

Next: decrypt `outputEnvelope` with the secret half of the output key, then read the receipt and check it. The checks are in [Verify a receipt](/docs/guides/verify-a-receipt).

| Code | When |
| --- | --- |

| `CALL_NOT_FOUND` | No call has this address. |

## `GET /v1/calls/{id}/stream`

Long-lived Server-Sent Events (`text/event-stream`) stream of live `call.piece` ([StreamPiece](#streampiece)) and terminal `call.stream.done` ([CallStreamDone](#callstreamdone)) events proxied from the call's enclave. Validates every frame against `ProgramEvent` and `call === {id}`, and aborts the upstream enclave request immediately when the client disconnects.

<Fields>
<Field name="after" type="integer, -1 or more (query parameter)">
Optional last piece index already received by the client. The stream replays every persisted piece with `index > after` before switching to live events (for example, `?after=4` resumes from piece `5`).
</Field>
</Fields>

| Code | When |
| --- | --- |
| `VALIDATION_ERROR` | `{id}` is not an address, or `after` is not an integer `-1` or greater. |
| `CALL_NOT_FOUND` | No call has this address. |
| `ENCLAVE_NOT_FOUND` | The API holds no enclave for the call's `enclave`. |
| `UPSTREAM_UNAVAILABLE` | The enclave did not accept the stream connection. Retryable. |

## `POST /v1/calls/{id}/stop`

Requests an immediate cooperative stop on a live per-token metered stream. The API proxies the request to the call's enclave, which checks `stopToken` in constant time against the 16-byte token sealed inside the caller's encrypted input envelope. On a match, the enclave stops generation, emits a terminal piece with `finishReason: "stopped"` (`deltaTokens: 0` when no pending tokens are buffered), and settles immediately via `settle_metered_call` at the current count, returning `ceiling - total` to the caller in the same transaction.

```http
POST /v1/calls/<call address>/stop
Content-Type: application/json

{
  "stopToken": "<16-byte caller stop token, base64>"
}
```

<Fields>
<Field name="stopToken" type="base64" required>
The caller's 16-byte stop token generated alongside `outputPublicKey` and sealed inside the encrypted input payload.
</Field>
</Fields>

Returns `StopCallAccepted`:

<Fields>
<Field name="call" type="address" required>
The Call account.
</Field>
<Field name="status" type="'stopping' | 'already-finished'" required>
`stopping` when the stop signal was accepted for an active stream; `already-finished` when the stream had already completed or settled.
</Field>
</Fields>

| Code | When |
| --- | --- |
| `VALIDATION_ERROR` | `{id}` is not an address, or `stopToken` is missing or not padded base64. |
| `UNAUTHORIZED` | `stopToken` does not match the token sealed in this call's input envelope (HTTP `403`). |
| `CALL_NOT_FOUND` | No call has this address. |
| `ENCLAVE_NOT_FOUND` | The API holds no enclave for the call's `enclave`. |
| `UPSTREAM_UNAVAILABLE` | The enclave did not answer or returned an invalid response. Retryable. |

## `POST /v1/calls/{id}/settle/build`

Builds [`settle_metered_call`](/docs/program/instructions#settlemeteredcall) so the caller (or operator) holding a signed stream piece can settle an open per-token call directly before `deadlineSlot`, paying `count * unitPrice` across owner, operator, and protocol and returning `ceiling - total` to `caller` in the same transaction.

```http
POST /v1/calls/<call address>/settle/build
Content-Type: application/json

{
  "wallet": "<caller or operator address>",
  "count": "<cumulative delivered token count, decimal u64>",
  "runningHash": "<64-hex running hash of the last signed piece>",
  "signature": "<64-byte enclave Ed25519 piece signature, base64>"
}
```

<Fields>
<Field name="wallet" type="address" required>
Must match either `call.caller` or `call.operator`. Signs the transaction and pays the 423-byte metered Receipt rent (plus any missing SPL associated token account rent) and transaction fee.
</Field>
<Field name="count" type="amount (u64 decimal string)" required>
Cumulative output token count of the signed piece (`count * unitPrice <= ceiling`).
</Field>
<Field name="runningHash" type="hash" required>
64-character hex `runningHash` of the signed piece.
</Field>
<Field name="signature" type="receipt signature" required>
Enclave Ed25519 signature over `voynich/piece/v1` (standalone) or `voynich/piece/v2` (adapter with `Model.base.sha256`). Verified pre-flight before the transaction is built.
</Field>
</Fields>

Returns a [Build](/docs/api/transactions#build) with `action: "settle_metered_call"` and `addresses: { model, call, receipt }`. The transaction prepends any missing SPL associated token account creations and the Ed25519 verification instruction before `settle_metered_call`.

| Code | When |
| --- | --- |
| `VALIDATION_ERROR` | `{id}` is not an address, fields fail schema validation, or `count * unitPrice` exceeds the call's `ceiling`. |
| `UNAUTHORIZED` | `wallet` is neither `call.caller` nor `call.operator` (HTTP `403`). |
| `CALL_NOT_FOUND` | No Call account has this address. |
| `CALL_NOT_OPEN` | The call already settled or was refunded. |
| `PROGRAM_REFUSED` | The call is not priced per token (`priceUnit !== 'token'`). |
| `CALL_DEADLINE_PASSED` | The current slot is past `deadlineSlot`; use `POST /v1/calls/{id}/refund/build` instead to recover 100% of `ceiling`. |
| `ENCLAVE_EXPIRED`, `MEASUREMENT_NOT_ALLOWED` | The enclave's attestation record is expired or its measurement is not allowed by the model. |
| `INVALID_ENVELOPE` | Pre-flight `verifyPiece` failed against the enclave's on-chain signing key. |
| `INSUFFICIENT_FUNDS` | `wallet` lacks lamports for the 423-byte Receipt rent, missing SPL ATAs, and fee. |

## `POST /v1/calls/{id}/refund/build`

Builds [`refund_call`](/docs/program/instructions#refundcall) for a call that passed its deadline without settling. The whole escrow returns to the caller, whoever sends the transaction.

```http
POST /v1/calls/<call address>/refund/build
Content-Type: application/json

{
  "wallet": "<address that signs and pays the fee>"
}
```

<Fields>
<Field name="wallet" type="address" required>
The wallet that sends the refund. It pays the fee and signs. It can be any wallet; the escrow goes to the call's `caller`.
</Field>
</Fields>

Returns a [Build](/docs/api/transactions#build). Its `action` is `refund_call` and its `addresses` hold `model` and `call`.

| Code | When |
| --- | --- |
| `VALIDATION_ERROR` | `{id}` is not an address. |
| `CALL_NOT_FOUND` | No Call account has this address. |
| `CALL_NOT_OPEN` | The call already settled or was refunded. |
| `CALL_NOT_REFUNDABLE` | The current slot is not past the call's `deadlineSlot`. |

Next: sign and submit the Build. `GET /v1/calls/{id}` then reads `refunded`. The whole task is in [Refund a call](/docs/guides/refund-a-call).

## `GET /v1/receipts/{id}`

Reads one receipt with what a client needs to check it. `{id}` is any of three things: the Receipt account's address, the address of its call, or the signature of the settling transaction.

<Fields>
<Field name="receipt" type="Receipt" required>
The [Receipt](#receipt).
</Field>
