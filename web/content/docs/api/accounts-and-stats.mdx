Eight routes cover account summaries, caller sessions, protocol counts, and the home summary. The errors every route shares are in [Overview](/docs/api/overview#on-every-route).

## `GET /v1/accounts/{wallet}`

Reads one wallet's side of the protocol in its three roles: the models it owns, the enclaves it operates and the calls it made. `{wallet}` is the wallet's address.

<Fields>
<Field name="wallet" type="address" required>
The wallet asked for.
</Field>
<Field name="models" type="array of Model" required>
The [Model](/docs/api/models#model) objects this wallet owns.
</Field>
<Field name="ownerEarnings" type="array of Money" required>
What the wallet was paid as an owner by settled calls, one [Money](/docs/api/overview#money) per mint.
</Field>
<Field name="enclaves" type="array of Enclave" required>
The [Enclave](/docs/api/enclaves#enclave) objects this wallet operates, in the order of [`GET /v1/enclaves`](/docs/api/enclaves#get-v1enclaves).
</Field>
<Field name="operatorEarnings" type="array of Money" required>
What the wallet was paid as an operator by settled calls, across every enclave it operates, one Money per mint.
</Field>
<Field name="calls" type="array of Call" required>
The [Call](/docs/api/calls-and-receipts#call) objects this wallet opened, latest opened first.
</Field>
</Fields>

Every list is whole, without pages. A wallet with nothing on the protocol returns empty arrays.

| Code | When |
| --- | --- |
| `VALIDATION_ERROR` | `{wallet}` is not an address. |

Next: a call whose `status` is `refundable` is refunded with [`POST /v1/calls/{id}/refund/build`](/docs/api/calls-and-receipts#post-v1callsidrefundbuild). An owned model is changed with the builds on [Models](/docs/api/models#builds). How earnings come about is in [Fees and the token](/docs/concepts/fees-and-the-token#the-split).

## Caller sessions

A `Session` PDA (`["session", caller, delegate, nonce_le]`) lets a caller deposit a capped budget once and authorize an ephemeral `delegate` keypair to open multiple calls without further wallet prompts. Each session object carries `address`, `caller`, `delegate`, `nonce`, `mint`, `model` (`null` for any model), `budget`, `spent`, `remaining`, `callsOpened`, `openedSlot`, `expiresAtSlot`, and `status` (`open` or `closed`).

### `GET /v1/accounts/{wallet}/sessions`

Lists every session opened by `{wallet}` (`{ wallet, items, asOf }`).

### `GET /v1/sessions/{address}`

Reads one `Session` by its PDA address. Answers `SESSION_NOT_FOUND` (`404`) when none exists.

### `POST /v1/sessions/build`

Builds [`open_session`](/docs/program/instructions#opensession): `{ wallet, delegate, budget, ttlSlots, mint?, model?, nonce?, delegateGasLamports? }`. Returns a Build with `action: "open_session"` and `addresses: { session }`.

### `POST /v1/sessions/{address}/close/build`

Builds [`close_session`](/docs/program/instructions#closesession): `{ wallet }`. Sweeps unspent `budget - spent` back to `session.caller` (callable by `caller` anytime, or by anyone after `expiresAtSlot`). Returns a Build with `action: "close_session"` and `addresses: { session }`. After `expiresAtSlot`, the protocol's `crank` service automatically sweeps expired open sessions every 5 seconds (creating the caller's SPL ATA idempotently when needed). On the site, `/account` lists open and closed sessions under **Active sessions** with one-press **Close & reclaim**.

### `POST /v1/sessions/{address}/call/build`

Builds [`open_session_call`](/docs/program/instructions#opensessioncall) (or [`open_session_metered_call`](/docs/program/instructions#opensessionmeteredcall) when `ceiling` is supplied for a per-token model), signed by `session.delegate` alone: `{ delegate, model, enclave, inputHash, answerMode?, nonce?, ceiling? }`. Returns a Build with `action: "open_session_call"` and `addresses: { model, session, call }`. Answers `SESSION_NOT_FOUND` (`404`) or `INVALID_SESSION` (`422`) if the session is closed, expired, mismatched, or out of budget.

## `GET /v1/stats`

Reads the protocol's counts.

<Fields>
<Field name="models" type="integer" required>
Models, in every status.
</Field>
<Field name="enclaves" type="integer" required>
Enclaves whose attestation record is unexpired at the current slot.
</Field>
<Field name="receipts" type="decimal string" required>
Receipts written.
</Field>
<Field name="callsSettled" type="decimal string" required>
Calls settled. Each settled call has one receipt, so it equals `receipts`.
</Field>
<Field name="programCalls" type="decimal string" required>
Calls opened by another Solana program through CPI (`callerIsProgram: true`).
</Field>
<Field name="operatorEarnings" type="array of Money" required>
What all operators were paid by settled calls, one [Money](/docs/api/overview#money) per mint.
</Field>
<Field name="currentSlot" type="slot" required>
The latest slot the API has read. Statuses that depend on a slot (`live` and `expired` enclaves and grants, `refundable` calls) are computed against it.
</Field>
<Field name="asOf" type="timestamp" required>
When the API assembled the response.
</Field>
</Fields>

Next: the models behind the counts are at [`GET /v1/models`](/docs/api/models#get-v1models) and the enclaves at [`GET /v1/enclaves`](/docs/api/enclaves#get-v1enclaves).

## `GET /v1/home`

Reads the summary a first screen shows: the counts, the model named `sketch-32`, the first bytes of its ciphertext and its latest receipts.

<Fields>
<Field name="stats" type="object" required>
The response of [`GET /v1/stats`](#get-v1stats).
</Field>
<Field name="model" type="Model or null" required>
The [Model](/docs/api/models#model) named `sketch-32`. `null` when it is not among the 100 models with the most settled calls.
</Field>
<Field name="ciphertext" type="object or null" required>
The first 256 bytes of the model's ciphertext, in the shape [`GET /v1/models/{id}/weights`](/docs/api/models#get-v1modelsidweights) returns. `null` when `model` is `null`.
</Field>
<Field name="recentReceipts" type="array of Receipt" required>
The model's 8 latest [Receipt](/docs/api/calls-and-receipts#receipt) objects, latest settling slot first. Empty when `model` is `null`.
</Field>
</Fields>

| Code | When |
| --- | --- |
| `UPSTREAM_UNAVAILABLE` | The model's Weights account could not be read from the cluster. Retryable. |

Next: call the model as in [Call a model in five minutes](/docs/start/call-a-model).
