---
title: Models and enclaves
description: Read sealed models, enclaves and a wallet's own side from code.
---

Eight read functions read what the API indexes from the chain (none needs a wallet, except `account` without an argument), and four write functions manage on-chain measurement records and model policies. Each returns the response of one HTTP route, typed and checked against the API's schema, so the fields are told once, on that route's page.

| Function | Returns | Route |
| --- | --- | --- |
| `models(query?)` | A page of models. | [`GET /v1/models`](/docs/api/models) |
| `model(id)` | One model, by name or address. | [`GET /v1/models/{id}`](/docs/api/models) |
| `listVersions(modelId, options?)` | The model's versions newest-first (`ModelVersions`). | [`GET /v1/models/{id}/versions`](/docs/api/models#get-v1modelsidversions) |
| `publishVersion(modelId, options)` | Encrypts new weights under the existing model key, uploads, seals and atomically publishes `version + 1`. | [`POST /v1/models/{id}/versions/build`](/docs/api/models#post-v1modelsidversionsbuild) |
| `policy(modelId)` | The model's active `ModelPolicy`, or `null` when none exists. | [`GET /v1/models/{id}/policy`](/docs/api/models#get-v1modelsidpolicy) |
| `setPolicy(modelId, input, options?)` | Signs `set_policy` and returns the indexed `ModelPolicy`. | [`POST /v1/models/{id}/policy/build`](/docs/api/models#post-v1modelsidpolicybuild) |
| `clearPolicy(modelId, options?)` | Signs `clear_policy` and returns the confirmed `TxStatus`. | [`POST /v1/models/{id}/policy/clear/build`](/docs/api/models#post-v1modelsidpolicyclearbuild) |
| `getSplit(modelId, options?)` | The model's `ModelSplit`, or `null` when none exists. | [`GET /v1/models/{id}/split`](/docs/api/models#get-v1modelsidsplit) |
| `setSplit(modelId, recipients, options?)` | Signs `set_split` and returns the indexed `ModelSplit`. | [`POST /v1/models/{id}/split/build`](/docs/api/models#post-v1modelsidsplitbuild) |
| `claimSplit(modelId, recipient?, options?)` | Signs `claim_split` and returns the confirmed `TxStatus`. | [`POST /v1/models/{id}/split/claim/build`](/docs/api/models#post-v1modelsidsplitclaimbuild) |
| `listBenchmarks(query?, options?)` | A page of verifiable benchmarks across all models (`BenchmarksPage`). | [`GET /v1/benchmarks`](/docs/api/models#get-v1benchmarks) |
| `listModelBenchmarks(modelId, query?, options?)` | A page of verifiable benchmarks for one model (`BenchmarksPage`). | [`GET /v1/models/{id}/benchmarks`](/docs/api/models#get-v1modelsidbenchmarks) |
| `publishBenchmark(modelId, input, options?)` | Signs `publish_benchmark` and returns the indexed `BenchmarkRecord`. | [`POST /v1/models/{id}/benchmarks/build`](/docs/api/models#post-v1modelsidbenchmarksbuild) |
| `getPassPlan(modelId, options?)` | The model's `PassPlan`, or `null` when none is configured. | [`GET /v1/models/{id}/pass-plan`](/docs/api/models#get-v1modelsidpass-plan) |
| `setPassPlan(modelId, input, options?)` | Signs `set_pass_plan` as the model owner and returns the indexed `PassPlan`. | [`POST /v1/models/{id}/pass-plan/build`](/docs/api/models#post-v1modelsidpass-planbuild) |
| `buyPass(modelId, callsTotal, options?)` | Signs `buy_pass` and returns the indexed `Pass`. | [`POST /v1/passes/buy/build`](/docs/api/accounts-and-stats#post-v1passesbuybuild) |
| `listPasses(wallet?, signal?)` | Prepaid passes held by `wallet` (or the signer's wallet). | [`GET /v1/accounts/{wallet}/passes`](/docs/api/accounts-and-stats#get-v1accountswalletpasses) |
| `pass(address)` | Handle `{ address, call(input, opts?), refresh(), close() }` for spending or closing a prepaid `Pass`. | [`GET /v1/passes/{address}`](/docs/api/accounts-and-stats#get-v1passesaddress) |
| `closePass(address, options?)` | Signs `close_pass` and returns `{ pass, transaction }`. | [`POST /v1/passes/close/build`](/docs/api/accounts-and-stats#post-v1passesclosebuild) |
| `getReferralConfig(modelId, options?)` | The model's `ReferralConfig`, or `null` when none is configured. | [`GET /v1/models/{id}/referral`](/docs/api/models#get-v1modelsidreferral) |
| `setReferralConfig(modelId, input, options?)` | Signs `set_referral_config` as the model owner and returns the indexed `ReferralConfig`. | [`POST /v1/models/{id}/referral/build`](/docs/api/models#post-v1modelsidreferralbuild) |
| `listReferrals(wallet?, signal?)` | Accrued referral balances for `wallet` (or the signer's wallet). | [`GET /v1/accounts/{wallet}/referrals`](/docs/api/accounts-and-stats#get-v1accountswalletreferrals) |
| `claimReferral(modelId, referrer?, options?)` | Signs `claim_referral` and returns `{ referral, transaction }`. | [`POST /v1/models/{id}/referral/claim/build`](/docs/api/models#post-v1modelsidreferralclaimbuild) |
| `listQuorums(query?, options?)` | A page of receipt-backed quorum calls across all models (`QuorumsPage`). | [`GET /v1/quorums`](/docs/api/models#get-v1quorums) |
| `listModelQuorums(modelId, query?, options?)` | A page of quorum calls for one model (`QuorumsPage`). | [`GET /v1/models/{id}/quorums`](/docs/api/models#get-v1modelsidquorums) |
| `quorum(address, options?)` | One `QuorumRecord` by its PDA address. | [`GET /v1/quorums/{address}`](/docs/api/models#get-v1quorumsaddress) |
| `openQuorum(modelId, input, options?)` | Signs `open_quorum` and returns the indexed `QuorumRecord`. | [`POST /v1/models/{id}/quorums/build`](/docs/api/models#post-v1modelsidquorumsbuild) |

| `enclaves(query?)` | A page of enclaves. | [`GET /v1/enclaves`](/docs/api/enclaves) |

| `getBond(enclaveKey, options?)` | The enclave's `OperatorBond`, or `null` when none exists. | [`GET /v1/enclaves/{key}/bond`](/docs/api/enclaves#get-v1enclaveskeybond) |
| `depositBond(enclaveKey, amountLamports, options?)` | Signs `deposit_bond` and returns the indexed `OperatorBond`. | [`POST /v1/enclaves/{key}/bond/deposit/build`](/docs/api/enclaves#post-v1enclaveskeybonddepositbuild) |
| `withdrawBond(enclaveKey, amountLamports, options?)` | Signs `withdraw_bond` and returns the indexed `OperatorBond`. | [`POST /v1/enclaves/{key}/bond/withdraw/build`](/docs/api/enclaves#post-v1enclaveskeybondwithdrawbuild) |
| `measurements(query?)` | A page of published measurement records. | [`GET /v1/measurements`](/docs/api/enclaves#get-v1measurements) |

| `account(wallet?)` | A wallet's models, enclaves, earnings and calls. | [`GET /v1/accounts/{wallet}`](/docs/api/accounts-and-stats) |

## models

```ts
const page = await voynich.models({ sort: 'newest', limit: 10 })
for (const model of page.items) console.log(model.name, model.price.amount, model.status)

const next = page.page.nextCursor ? await voynich.models({ cursor: page.page.nextCursor }) : null
```

<Fields>
<Field name="sort" type="'calls' | 'newest' | 'price'">
The order. `calls` by default.
</Field>
<Field name="limit" type="number">
Models per page, 1 to 100. 24 by default.
</Field>
<Field name="cursor" type="string">
The `nextCursor` of the page before.
</Field>
</Fields>

A page is `{ items, page: { nextCursor, hasMore }, asOf }`. `nextCursor` is `null` on the last page.

## model

```ts
const model = await voynich.model('sketch-32')
console.log(model.manifest.labels)
```

Takes the model's name or address. Throws an `ApiClientError` with `MODEL_NOT_FOUND` when there is none.

## listVersions and publishVersion

```ts
const history = await voynich.listVersions('text-1m')

const published = await voynich.publishVersion('text-1m', {
  weights: nextAdapterBytes,
  modelKey, // optional: derived via signSealDerivation when omitted
})
console.log(published.version, published.ciphertextSha256, published.transactionsSent)
```

`listVersions(modelId, options?)` reads `GET /v1/models/{id}/versions` and returns `{ model, currentVersion, items, asOf }`. `publishVersion(modelId, options)` requires the model owner's signer (`WALLET_REQUIRED`), encrypts `options.weights` under `options.modelKey` (or derives it via `signSealDerivation`), allocates new `Weights` accounts, runs `begin_version`, `write_version_weights`, `seal_version_range`, and `publish_version`, waits for indexing, and resolves to `{ model, version, ciphertextSha256, noncePrefix, transactionsSent }`.

## policy, setPolicy and clearPolicy

```ts
const current = await voynich.policy('sketch-32')

const updated = await voynich.setPolicy('sketch-32', {
  allowListEnabled: true,
  allowedCallers: [callerAddress],
  allowedOperators: [operatorAddress],
})

const cleared = await voynich.clearPolicy('sketch-32')
```

`policy(modelId)` reads the model's active `ModelPolicy` and returns `null` when the API answers `POLICY_NOT_FOUND`. `setPolicy(modelId, input, options?)` requires the model owner's signer (`WALLET_REQUIRED`), submits `set_policy`, waits for indexing, and resolves to the updated `ModelPolicy`. `clearPolicy(modelId, options?)` closes the `Policy` PDA, returns its rent to the owner, and resolves to `TxStatus`.

## getSplit, setSplit and claimSplit

```ts
const split = await voynich.getSplit('sketch-32')

const updated = await voynich.setSplit('sketch-32', [
  { wallet: authorA, shareBps: 5000 },
  { wallet: authorB, shareBps: 3000 },
  { wallet: authorC, shareBps: 2000 },
])

const claimed = await voynich.claimSplit('sketch-32', authorB)
```

`getSplit(modelId)` reads `GET /v1/models/{id}/split` and returns `null` on `SPLIT_NOT_FOUND`. `setSplit(modelId, recipients)` requires the model owner's signer (`1..8` recipients summing to `10,000` bps, or `[]` to deactivate). `claimSplit(modelId, recipient?)` is permissionless (`recipient` defaults to the signer's wallet) and releases `accrued - claimed` directly to `recipient`.

## listBenchmarks, listModelBenchmarks and publishBenchmark

```ts
const all = await voynich.listBenchmarks({ name: 'sketch-eval-v1' })
const forModel = await voynich.listModelBenchmarks('sketch-32')

const published = await voynich.publishBenchmark('sketch-32', {
  name: 'sketch-eval-v1',
  datasetSha256,
  datasetUri: 'https://example.com/evals/sketch-eval-v1.json',
  sampleCount: 10,
  passedCount: 9,
  receipts: [receiptA, receiptB],
})
console.log(published.scoreBps, published.modelVersion, published.receipts)
```

`listBenchmarks(query?)` reads `GET /v1/benchmarks` (filtering optionally by `model`, `name`, `limit`, `cursor`). `listModelBenchmarks(modelId, query?)` reads `GET /v1/models/{id}/benchmarks`. `publishBenchmark(modelId, input, options?)` is permissionless (any configured signer, `WALLET_REQUIRED`), computes `scoreBps = Math.floor((passedCount * 10000) / sampleCount)` when omitted, submits `publish_benchmark` with the cited `Receipt` PDAs in remaining accounts, waits for indexing, and resolves to `BenchmarkRecord`.

## Prepaid passes (`getPassPlan`, `setPassPlan`, `buyPass`, `pass`, `closePass`)

```ts
const plan = await voynich.setPassPlan('sketch-32', {
  pricePerCall: 800_000n,
  minCalls: 3,
  maxCalls: 100,
  ttlSlots: 100_000n,
  active: true,
})

const purchased = await voynich.buyPass('sketch-32', 10)
const handle = voynich.pass(purchased.address)
const res = await handle.call(drawing)
const { pass: closed } = await handle.close()
```

`getPassPlan(modelId)` reads `GET /v1/models/{id}/pass-plan` and returns `null` on `PASS_PLAN_NOT_FOUND`. `setPassPlan(modelId, input)` requires the model owner's signer (`WALLET_REQUIRED`). `buyPass(modelId, callsTotal, opts?)` funds a 154-byte `Pass` PDA at `plan.pricePerCall * callsTotal`. Pass `pass: purchased.address` in `call(modelId, input, { pass })` or use `voynich.pass(address).call(input)` to spend prepaid calls at the discounted rate, and `closePass(address)` (or `handle.close()`) to reclaim any unused escrow.

## Referral shares (`getReferralConfig`, `setReferralConfig`, `listReferrals`, `claimReferral`)

```ts
const cfg = await voynich.setReferralConfig('sketch-32', { shareBps: 500, active: true })
const res = await voynich.call('sketch-32', drawing, { referrer: referrerWallet })
const referrals = await voynich.listReferrals(referrerWallet)
const { referral } = await voynich.claimReferral('sketch-32', referrerWallet)
```

`getReferralConfig(modelId)` reads `GET /v1/models/{id}/referral` and returns `null` on `REFERRAL_CONFIG_NOT_FOUND`. `setReferralConfig(modelId, { shareBps, active })` requires the model owner's signer (`shareBps <= 2500`). Passing `referrer` in `call(modelId, input, { referrer })` appends `register_call_referral` in the same transaction as `open_call`, carving `floor(owner_amount * shareBps / 10_000)` to the referrer on settlement (coexisting with `Split`). `claimReferral(modelId, referrer?)` is permissionless and releases `totalEarned - claimed` directly to `referrer`.

## Quorum calls (`listQuorums`, `listModelQuorums`, `quorum`, `openQuorum`, `finalizeQuorum`)

```ts
const q = await voynich.openQuorum('sketch-32', {
  inputHash,
  requiredVotes: 2,
  requireDistinctEnclaves: true,
})

const { quorum: agreed } = await voynich.finalizeQuorum(q.address, [receiptA, receiptB])
console.log(agreed.status, agreed.agreedOutputHash, agreed.distinctEnclaves)
```

`listQuorums(query?)` reads `GET /v1/quorums` (filtering optionally by `model`, `caller`, `status`, `limit`, `cursor`). `listModelQuorums(modelId, query?)` and `quorum(address)` read model and single-quorum snapshots. `openQuorum(modelId, { inputHash, requiredVotes, requireDistinctEnclaves?, nonce? })` creates a 326-byte `Quorum` PDA (`2..=5` votes), and `finalizeQuorum(address, receipts)` permissionlessly verifies the cited `Receipt` PDAs on chain and seals `status: 'agreed'`.

## enclaves and enclave

```ts
const enclaves = await voynich.enclaves()
const detail = await voynich.enclave(enclaves.items[0]!.address)
console.log(detail.earnings)
```

`enclaves` takes `limit` and `cursor` as `models` does. It lists live and reachable enclaves first; each Enclave's `reachable` and `lastSeen` are told in [Reachability](/docs/api/enclaves#reachability). `enclave` takes an enclave's address or its signing key and returns `{ enclave, grants, receipts, earnings }`. It throws `ENCLAVE_NOT_FOUND` when there is none.

## getBond, depositBond and withdrawBond

```ts
const bond = await voynich.getBond(enclaveKey)

const topped = await voynich.depositBond(enclaveKey, 500_000_000n)
const reduced = await voynich.withdrawBond(enclaveKey, 100_000_000n)
console.log(reduced.bondedLamports, reduced.missedCalls, reduced.slashedTotal)
```

`getBond(enclaveKey, options?)` reads `GET /v1/enclaves/{key}/bond` and returns `null` on `BOND_NOT_FOUND`. `depositBond(enclaveKey, amountLamports, options?)` and `withdrawBond(enclaveKey, amountLamports, options?)` accept `bigint | number | string` lamports, require the enclave operator's signer (`WALLET_REQUIRED`), submit the built transaction, wait for indexing, and resolve to the updated `OperatorBond`.

## measurements, publishMeasurement and deprecateMeasurement

```ts
const active = await voynich.measurements({ status: 'active' })
const record = await voynich.measurement(digest)

const published = await voynich.publishMeasurement({
  digest,
  sourceRepo: 'https://github.com/...',
  commitSha,
  recipeHash,
  version: '0.1.3',
})

const deprecated = await voynich.deprecateMeasurement(digest)
```

`measurements` takes `status` (`'active' | 'deprecated'`), `limit`, and `cursor`. `measurement` takes a 96-character hex SHA-384 digest and throws `MEASUREMENT_NOT_FOUND` when none exists on chain. `publishMeasurement` and `deprecateMeasurement` require a configured signer (`WALLET_REQUIRED`), submit the built transaction, wait for indexing, and resolve to the updated `MeasurementRecord`. For the same operations from the terminal (including rebuilding from source to verify a published digest), see [CLI: measurement](/docs/cli/measurement).

## account

```ts
const mine = await voynich.account()
const theirs = await voynich.account(wallet)
```

Without an argument it reads the signer's own wallet, and throws `WALLET_REQUIRED` when the client has none. It returns `{ wallet, models, ownerEarnings, enclaves, operatorEarnings, calls }`. A call whose `status` is `refundable` can be passed to [refund](/docs/sdk/grant-and-refund#refund).

## Every other route

`voynich.api` is the typed client of the whole [HTTP API](/docs/api/overview): the model's ciphertext (`api.weights`), its enclaves and receipts (`api.modelEnclaves`, `api.modelReceipts`), receipts and calls (`api.receipt`, `api.call`, `api.answer`), the counts (`api.stats`), the configuration (`api.config`) and every transaction build. Each method is named after its route's operation in the [route list](/docs/api/overview).
