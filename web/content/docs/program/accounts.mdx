title: Accounts

The `voynich` program is an Anchor program. Its address on a cluster is `programId` in `GET /v1/config`. Every account below starts with an 8-byte discriminator. All but Weights are Borsh-encoded after it. Integers are little-endian.

<Rows data="program-accounts" columns="account,discriminator,fields,bytes" />

`bytes` is the encoded length of an account whose fields are all fixed in size. Model, Enclave, Grant, Call and Receipt hold strings or lists, so their length varies inside the space they are created with.

| Account | Address | Space | Rent paid by |
| --- | --- | --- | --- |
| Config | PDA `["config"]` | 118 bytes (116 bytes before migration) | the admin |
| Model | PDA `["model", name]` | 8,192 bytes (6,000 bytes legacy) | the owner |
| ModelVersion | PDA `["version", model, version_le]` | 8,192 bytes | the owner |
| Weights | any address, created by the owner | 56 bytes plus its ciphertext | the owner |
| Enclave | PDA `["enclave", signing_key]` | 470 bytes | the operator |
| Measurement | PDA `["measurement", digest[..32], digest[32..]]` | 366 bytes | the publisher |
| Policy | PDA `["policy", model]` | 1,770 bytes | the model's owner |
| Grant | PDA `["grant", model, enclave]` | 226 bytes (223 bytes legacy) | the grant's payer |
| Call | PDA `["call", caller, nonce]` | 349 bytes plus 33 bytes per callback account (302, 303, 304 or 340 + 33 * N legacy) | the payer |
| Receipt | PDA `["receipt", call]` | 407 bytes plus `open_answer` (423 bytes for metered calls; 401 or 406 plus `open_answer` legacy) | the settling payer |
| Session | PDA `["session", caller, delegate, nonce]` | 186 bytes | the caller |
| Split | PDA `["split", model]` | 526 bytes | the model's owner |
| Bond | PDA `["bond", enclave]` | 107 bytes | the enclave's operator |
| Benchmark | PDA `["benchmark", model, name]` | 843 bytes | the publisher (permissionless) |
| PassPlan | PDA `["pass-plan", model]` | 138 bytes | the model's owner |
| Pass | PDA `["pass", model, holder, nonce]` | 154 bytes | the pass holder |
| ReferralConfig | PDA `["referral-config", model]` | 52 bytes | the model's owner |
| Referral | PDA `["referral", model, referrer]` | 137 bytes | the first referring caller |
| CallReferral | PDA `["call-referral", call]` | 108 bytes | the call's caller |

In a seed, `name` is the model's name as UTF-8, an address is its 32 bytes, and `nonce` is 8 bytes little-endian.

## Model

One per sealed model, at PDA `["model", name]`. Created by `create_model`. Changed by `attach_weights`, `seal_range`, `seal_model`, `set_price`, `set_allowed_measurements`, `set_policy`, `clear_policy`, `set_split`, `publish_version`, `retire_model`, `grant_by_owner` and `settle_call`.

<Rows data="account-model" columns="field,type,meaning" />

`status` is one byte: 0 `Uploading`, 1 `Sealed`, 2 `Live`, 3 `Retired`. `price_unit` is one byte: 0 `Call`, 1 `Token`. A measurement is 48 bytes. `ModelBase` is `sha256: [u8; 32]`, `size_bytes: u64`, `format: string` (`onnx`, `safetensors` or `gguf`, at most 32 bytes), and `source: string` (1 to 256 bytes starting with `https://`, `http://`, `ipfs://` or `hf://`, no ASCII whitespace or control bytes). Legacy 6,000-byte and earlier 8,192-byte Model accounts decode trailing zeros as `base: None`, `price_unit: Call`, `has_policy: false`, `current_version: 0` (interpreted as `1` via `effective_version()`) and `has_split: false`. What these facts mean is in [Sealed models](/docs/concepts/sealed-models).

## ModelVersion

One per staged or published upgrade of a live model, at PDA `["version", model, version_le]` (`ModelVersion::SPACE = 8,192` bytes, where `version_le` is `version: u32` in little-endian). Created in `Uploading` by `begin_version`, populated by `write_version_weights` and `seal_version_range`, and flipped to `Live` by `publish_version`.

<Rows data="account-model-version" columns="field,type,meaning" />

`status` is one byte: 0 `Uploading`, 1 `Live`, 2 `Archived`. While a new `ModelVersion` uploads, the parent `Model` stays `Live` on its current version; `publish_version` atomically swaps `Model`'s active weights, hash, manifest, base, nonce prefix and `current_version` without invalidating existing `Grant` accounts.

## Weights

A Weights account holds ciphertext. It is not an Anchor-typed account: the program reads and writes it in place. It is a 56-byte header followed by the ciphertext bytes.

| Offset | Bytes | Field | Meaning |
| --- | --- | --- | --- |
| 0 | 8 | discriminator | Set by `create_model`. |
| 8 | 32 | `model` | The Model the account belongs to. |
| 40 | 4 | `index` | Its place in the model's `weights` list, from 0. |
| 44 | 4 | `size_bytes` | The ciphertext bytes it holds: its data length minus 56. |
| 48 | 4 | `written_bytes` | The highest end written so far. Equal to `size_bytes` once the account is written to its end. |
| 52 | 4 | `reserved` | Global ciphertext byte offset of this account (`0` for legacy models). |
| 56 | `size_bytes` | ciphertext | The model's ciphertext from this account's offset on. |

The owner creates each Weights account before attaching it: owned by the `voynich` program, rent-exempt, with its first 56 bytes zero, and between 57 bytes and 10 MiB long. A model has 1 to 64 of them (initial batch up to 8 in `create_model`, further accounts in `attach_weights`). The ciphertext of the model is the ciphertext of its Weights accounts in order, and their sizes add up to the Model's `size_bytes`.

## Measurement

One per published 48-byte SHA-384 enclave runtime measurement, at PDA `["measurement", digest[..32], digest[32..]]` (splitting the 48-byte digest across two seeds within Solana's 32-byte seed limit). Created by `publish_measurement` (`366` bytes). Marked `Deprecated` by `deprecate_measurement`.

<Rows data="account-measurement" columns="field,type,meaning" />

`status` is one byte: 0 `Active`, 1 `Deprecated`. `source_repo` is 1 to 128 bytes and `version` is 1 to 32 bytes (no ASCII whitespace or control characters); `commit_sha` is 7 to 64 hex characters; `digest` and `recipe_hash` are non-zero.

## Policy

Optional per-model owner policy, at PDA `["policy", model]` (`Policy::SPACE = 1,770` bytes). Created or updated in place by `set_policy` (setting `model.has_policy = true`) and closed by `clear_policy` (returning its rent to the owner and setting `model.has_policy = false`).

<Rows data="account-policy" columns="field,type,meaning" />

Limits: at most 32 unique `allowed_callers`, 16 unique `allowed_operators`, and 8 unique `allowed_regions` (each 1 to 16 lowercase letters, digits or hyphens). `max_calls_per_caller_per_window` and `window_slots` must both be `0` or both positive. When `model.has_policy` is true, `open_call`, `open_metered_call`, `grant_by_owner` and `grant_by_enclave` require the canonical Policy PDA in remaining accounts (`PolicyRequired` if omitted).

## Grant

One per model and enclave, at PDA `["grant", model, enclave]`. Written by `grant_by_owner` and `grant_by_enclave`, marked by `revoke_grant`, and optionally quoted by `set_quote`.

<Rows data="account-grant" columns="field,type,meaning" />

Legacy 223-byte `Grant` accounts decode `quoted_operator_share_bps` as `None` (using `model.operator_share_bps`). Calling `set_quote` reallocates a legacy 223-byte Grant in place to `Grant::SPACE` (`226` bytes, rent difference paid by `enclave.operator`).

## Call

One per call, at PDA `["call", caller, nonce]`. Created by `open_call` or `open_metered_call`. Changed by `settle_call` and `refund_call`.

<Rows data="account-call" columns="field,type,offset,meaning" />

`status` is one byte: 0 `Open`, 1 `Settled`, 2 `Refunded`. `answer_mode` is one byte: 0 `Sealed`, 1 `Open`. `price_unit` is one byte: 0 `Call`, 1 `Token`. Each `CallbackAccount` is 33 bytes: `pubkey` (32 bytes) followed by `is_writable` (`bool`, 1 byte), up to 8 entries. `Call::escrow_amount()` returns `price` for `PriceUnit::Call` and `ceiling` for `PriceUnit::Token`.

The owner, operator, fee recipient, price, price unit, ceiling and both shares are copied into the Call when it opens. A price change, a new fee recipient or a new share after that leaves an open call as it was.

An escrow in SOL is held as lamports in the Call account itself, above its rent. An escrow in a mint is held in the Call's associated token account for that mint.

## Receipt

One per settled call, at PDA `["receipt", call]`. Created by `settle_call` (per-call) or `settle_metered_call` (per-token) and never changed.

<Rows data="account-receipt" columns="field,type,offset,meaning" />

`owner_amount`, `operator_amount` and `protocol_amount` add up to `total`. Flat per-call receipts stay at `407 + open_answer.len()` bytes. A metered receipt created by `settle_metered_call` writes the exact 407-byte `Receipt` prefix (`answer_mode = Sealed`, `open_answer = []`, `output_hash = running_hash`, `total = count * price`) followed by 16 trailing bytes (`Receipt::METERED_SPACE = 423`): `delivered_count: u64` (offset 407) and `returned_amount: u64` (offset 415). Opening a call via CPI and verifying a Receipt from your own program is in [Calling a model from a program](/docs/program/calling-a-model).

## Session

One per delegated caller budget, at PDA `["session", caller, delegate, nonce_le]` (`Session::SPACE = 186` bytes). Created by `open_session`, debited by `open_session_call` and `open_session_metered_call`, and closed by `close_session`.

<Rows data="account-session" columns="field,type,offset,meaning" />

`status` is one byte: 0 `Open`, 1 `Closed`. A SOL session holds its `budget - spent` lamports inside the Session PDA above rent; an SPL session holds its budget in its associated token account `session_escrow`. Delegated calls write the exact same `Call` PDA with `call.caller = session.caller`, keeping `Policy` allow lists, `settle_call`, `settle_metered_call`, `refund_call`, `Receipt`, and enclave verification unchanged.

## Split

Optional per-model owner revenue split, at PDA `["split", model]` (`Split::SPACE = 526` bytes). Created, updated, or deactivated by `set_split`, credited during `settle_call` and `settle_metered_call` when `model.has_split` is true, and claimed per recipient via permissionless `claim_split`.

<Rows data="account-split" columns="field,type,meaning" />

Each `SplitRecipient` holds `wallet: pubkey`, `share_bps: u16`, `accrued: u64`, and `claimed: u64` (up to `MAX_SPLIT_RECIPIENTS = 8` unique non-default wallets summing to `10,000` bps when active). Rounding dust from `floor(owner_amount * share_bps / 10_000)` goes to `recipients[0]` so `sum(accrued) == total_received` to the exact base unit.

## Bond

Optional per-enclave operator SOL bond, at PDA `["bond", enclave]` (`Bond::SPACE = 107` bytes). Created and topped up by `deposit_bond`, withdrawn from by `withdraw_bond`, and optionally slashed on timed-out calls inside `refund_call`.

<Rows data="account-bond" columns="field,type,offset,meaning" />

`bonded_lamports` sits inside the Bond PDA above rent-exemption (`DEFAULT_BOND_SLASH_BPS = 1000`, 10%). When `refund_call` receives the writable canonical `Bond` PDA (`["bond", call.enclave]`) in remaining accounts and `bonded_lamports > 0`, it slashes `min(bonded_lamports, escrow * slash_bps / 10_000)` for SOL calls (or `min(bonded_lamports, 1_000_000)` lamports for SPL calls) directly to `call.caller`, increments `slashed_total` and `missed_calls`, and emits `BondSlashed`.

## Benchmark

Immutable per-model verifiable benchmark score, at PDA `["benchmark", model, name]` (`Benchmark::SPACE = 843` bytes). Created permissionlessly by `publish_benchmark` by any wallet (owner or third-party evaluator).

<Rows data="account-benchmark" columns="field,type,meaning" />

`name` is a 1 to 32 byte ASCII slug (`[a-z0-9-]`), `dataset_uri` is 1 to 160 bytes (`https://`, `http://`, `ipfs://`, or `hf://`, no whitespace or control characters), `score_bps` equals `floor(passed_count * 10_000 / sample_count)`, and `receipts` lists 1 to 16 unique canonical `Receipt` PDAs verified on chain against `model` across all Receipt eras during `publish_benchmark`.

## PassPlan

Optional per-model discounted prepaid pass plan, at PDA `["pass-plan", model]` (`PassPlan::SPACE = 138` bytes). Created, updated, or deactivated by `set_pass_plan` for per-call (`PriceUnit::Call`) models.

<Rows data="account-pass-plan" columns="field,type,offset,meaning" />

When `active` is true, `0 < price_per_call <= model.price`, `min_calls >= 1`, `max_calls >= min_calls`, and `ttl_slots > 0`.

## Pass

One per purchased prepaid call pack, at PDA `["pass", model, holder, nonce_le]` (`Pass::SPACE = 154` bytes). Created by `buy_pass`, debited by `open_pass_call`, and closed by `close_pass`.

<Rows data="account-pass" columns="field,type,offset,meaning" />

`status` is one byte: 0 `Open`, 1 `Closed`. A SOL pass holds `escrow_remaining` lamports inside the Pass PDA above rent; an SPL pass holds `escrow_remaining` in its associated token account `pass_escrow`. Calls opened through `open_pass_call` write the exact same `Call` PDA with `call.price = pass.price_per_call`, keeping `Policy`, `Grant` quoted share, `settle_call`, `refund_call`, `Receipt`, and enclave verification unchanged.

## ReferralConfig

Optional per-model referral share configuration, at PDA `["referral-config", model]` (`ReferralConfig::SPACE = 52` bytes). Created, updated, or deactivated by `set_referral_config` (`share_bps <= MAX_REFERRAL_SHARE_BPS = 2500`, 25% of `owner_amount`).

Initialized if needed by `register_call_referral`, credited during `settle_call` / `settle_metered_call` when referral remaining accounts are attached, and claimed permissionlessly via `claim_referral`.
